The first stable MCHorizonUWP Builder release checks every Horizon native-mod version against the selected Horizon commit and hook API before opening the mod picker. Incompatible releases are disabled with a reason, and compatible selections are pinned to the exact versions shown in the build summary.

The Horizon release picker shows the upstream commit and matching nightly name. The mod picker now keeps its text and alphabetical index visible within the dialog. The finished page supports in-place upgrades when the installed package uses the same architecture and provides installation guidance for Windows, Xbox, Windows 10 Mobile and Windows Core OS devices.

Extract the ZIP and run Horizon.Builder.App.exe. See README.md and THIRD_PARTY_NOTICES.md for project and dependency information.
